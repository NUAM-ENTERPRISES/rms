# WhatsApp Candidate Status Templates

Ready-to-submit **Utility** templates for Meta Business Manager (WhatsApp Manager → Message Templates).

**Language:** English (`en_US`)  
**Category:** Utility  
**Footer (optional, all templates):** `Reply STOP to opt-out`

## Variable convention

| Variable | Meaning |
|----------|---------|
| `{{1}}` | Candidate first name |
| `{{2}}` | Role / project name |
| `{{3}}` | Date, time, or extra detail (when needed) |

---

## 1. Interested

**Template name:** `candidate_status_interested`  
**Use when:** Candidate is marked as interested

**Body:**

```
Hello {{1}},

Thank you for your interest in the {{2}} opportunity with Affiniks.

Our recruitment team will contact you within 24–48 hours with the next steps.

Please keep your phone available.

Best regards,
Affiniks RMS Team
```

**Sample values:**

- `{{1}}`: Rajesh
- `{{2}}`: Staff Nurse – UAE

## How to create in Meta Business Manager

1. Go to [business.facebook.com](https://business.facebook.com)
2. Open **WhatsApp Manager** → **Message Templates**
3. Click **Create Template**
4. Set **Category** to **Utility** and **Language** to **English**
5. Paste the body text for the template
6. Fill in sample values for approval
7. Submit and wait 24–48 hours for approval

---

Map each RMS status to the matching template name so notifications are sent automatically on status change.
